CaseFlow 案件指派系统 · 操作教程

按角色分册 · 快速上手版

一、系统简介与登录

CaseFlow 是面向公安机关的案件指派与办理系统，覆盖「收案 → 指派 → 盯办 → 结案」全流程。系统按账号角色开放不同功能，本教程按角色分册说明。

图 1 · 登录页

二、角色一览

系统共分四类角色，侧栏菜单随角色不同而不同：

角色落地页可用栏目核心能力
普通民警我的案件我的案件 / 我的待办 / 到期提醒 / 工作记录本办理自己承办的案件、提交反馈
研判员案件管理案件管理查看全量案件、编辑嫌疑人、维护时间节点
业务领导（所长/副所长/队长/法制员/案管）工作台工作台 / 案件盯办 / 待办总览 / 案件管理 / 到期提醒指派、下达意见、审批、结案、状态变更
系统管理员工作台业务栏目 + 人员图谱 / 类别管理 / 账号管理全部业务权限 + 系统运维
分册一 · 普通民警

3.1 我的案件

登录后自动进入「我的案件」，这里只显示本人名下承办的案件。可以看到案件状态、截止期限、办案阶段等信息。

图 2 · 普通民警「我的案件」

3.2 我的待办

「我的待办」列出领导指派给您的待办事项。完成工作后点「详情」提交反馈说明，勾选完成需领导确认。

图 3 · 普通民警「我的待办」

3.3 到期提醒

「到期提醒」汇总本人名下案件的期限情况，已逾期、今天到期、即将到期的案件会分桶提示，避免漏办。

图 4 · 普通民警「到期提醒」

分册二 · 研判员

4.1 案件管理（唯一栏目）

研判员登录后进入「案件管理」，侧栏只有这一项。可查看全所全量案件，通过顶部筛选（状态、经办人、到期、更多筛选等）快速定位。

图 5 · 研判员「案件管理」

4.2 研判员可编辑：嫌疑人 + 时间节点

打开案件详情，研判员可「新增嫌疑人」录入身份信息、可「新增节点」维护重要时间节点；其余（待办反馈、状态变更、结案、案件编辑等）均为只读，仅能查看。

图 6 · 研判员案件详情（嫌疑人/时间节点可编辑，其余只读）

分册三 · 业务领导（所长 / 副所长 / 队长 / 法制员 / 案管）

5.1 工作台

工作台是全所案件的统计总览，含案件趋势、维度分布、强制措施到期、待审批（措施审批 / 状态变更 / 待确认结案 / 结案异议）等。领导在此集中处理审批。

图 7 · 业务领导「工作台」

5.2 案件盯办

「案件盯办」按侦查进度分模块盯办案件，可登记强制措施、推进阶段流转、审批承办人的变更申请。

图 8 · 业务领导「案件盯办」

5.3 待办总览

「待办总览」汇总各案件的待办完成情况，领导可在此下达意见、定级、催办。

图 9 · 业务领导「待办总览」

分册四 · 系统管理员

6.1 账号管理

「账号管理」用于新建/审核/停用账号。顶部可设置「案件阶段变更模式」与「结案模式」两个全局开关（自动 / 手动确认 / 两套都要）。

图 10 · 系统管理员「账号管理」（含两个全局开关）

6.2 人员图谱

「人员图谱」维护组织架构与员工档案，部门、职务、警号等在此统一管理。

图 11 · 系统管理员「人员图谱」

6.3 类别管理

「类别管理」维护案件大类与小类字典，供案件分类检索使用。

图 12 · 系统管理员「类别管理」

七、结案说明（刑事 / 行政结果不同）

结案结果按案件类型区分：刑事案件＝撤案 / 移送预审 / 移送其他单位；行政案件＝处罚 / 不予处罚 / 终止调查 / 调解。撤案落地为「已撤销」，其余落地为「已办结」。

提示：系统对数据库「只增不改」，所有升级均不覆盖、不清空已录入的业务数据，内网已有数据安全无虞。
