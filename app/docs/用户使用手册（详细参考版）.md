## 第 1 章 登录、注册、账号审核

### 1.1 登录

1. 浏览器打开系统地址（如 `http://192.168.1.10:8080/api/`）。
2. 输入**用户名或手机号** + 密码，点「登 录」（直接回车也可以）。
3. 页面底部的标语每天会自动更换。

登录后落点由角色决定：

- **民警 → 我的案件**，并自动弹出「欢迎回来」汇总窗。
- **领导/管理员 → 工作台**。

> 底部「还没有账号？注册账号」——新同事从这里自助注册。

### 1.2 注册（自助申请）

点「注册账号」，页面顶部黄条会先说清一件事：**提交后需所长或法制员审核通过才能登录**。

按从左到右填：

| 字段 | 必填 | 说明 |
|---|---|---|
| 手机号 | ✅ | 11 位。可直接用来登录 |
| 密码 / 确认密码 | ✅ | 至少 6 位 |
| 真实姓名 | ✅ | 最多 64 字 |
| 登录名 | ❌ | 留空就用手机号登录；填了至少 3 个字符 |
| 所属部门 | ❌ | 可搜索，也可以直接输入新部门名 |
| 申请角色 | ✅ | 默认「普通民警」 |
| 办案组别 | **民警必填** | 初查组 / 清案组 / 不限，见下方说明 |
| 关联员工 | ✅ | 搜姓名/工号/部门，认领本人在组织架构中的档案 |

**办案组别怎么选**（决定你能接什么活）：

- **初查组** —— 只能承接初查任务
- **清案组** —— 只能承接刑拘在办案件
- **不限** —— 可承接各类案件

**找不到自己的档案？** 点「＋ 新建员工档案」现场建，填姓名、部门、职务（领导/副领导/组长/组员，默认「组员」）、工号（选填）。建完会回填到姓名、部门。**必须是本人的档案，一名员工只能绑定一个账号。**

提交成功后提示原文：

> 注册申请已提交。登录名：XXX（也可用手机号登录）。已同时为其建立员工档案「XXX」。请等待所长或法制员审核，审核通过后即可登录。

### 1.3 审核与常见登录失败

登录时可能看到这些提示，对应处理：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 账号正在等待审核，请联系所长或法制员审核通过后再登录 | 已提交未审核 | 找所领导 |
| 注册申请未通过（带驳回原因） | 被驳回 | 按驳回原因找管理员重提 |
| 账号已停用，请联系管理员 | 被停用 | 找管理员恢复 |
| 账号不存在。可以用用户名或注册手机号登录 | 输错了 | 检查大小写、用手机号试 |
| 登录已过期，请重新登录 | 令牌失效（后端重启等） | 重新登录即可，属正常 |

> **后端重启后所有人会被强制下线一次**，这是设计如此（会话保存在服务进程内存中）。重新登录即可，不影响任何数据。

## 第 2 章 角色与权限：你该找谁、你能做什么

### 2.1 五个角色

| 角色 | 业务权限 | 额外能管的事 |
|---|---|---|
| **普通民警** STAFF | 只看自己名下案件，办案、写反馈 | — |
| **所长** CHIEF | 全部业务权限 | — |
| **副所长** DEPUTY_CHIEF | 全部业务权限 | — |
| **法制员** LAW_OFFICER | 全部业务权限 | — |
| **系统管理员** BOSS | 全部业务权限 | 账号管理、员工图谱、类别管理 |

> **一个重要区别**：所长/副所长/法制员与系统管理员的**业务权限完全一样**（都能建案、指派、批注、撤回）。差别只在于「能不能进系统管理那三个页面」。系统管理员是内建的最高账号，**不开放自助注册**。

### 2.2 侧栏菜单按角色显示

**民警（3 项）**：我的案件、我的待办、到期提醒
（我的待办菜单上带红点＝你有未完成的待办，含即将超期的）

**领导（5 项）**：工作台、案件盯办、待办总览、案件管理、到期提醒

**系统管理员（领导 5 项 + 3 项）**：另加 员工图谱、类别管理、账号管理
（账号管理菜单上带红点＝有待审核的注册申请）

顶栏常驻：当天日期、**通知铃铛**（未读数超 99 显示 `99+`）、姓名 + 角色徽章、「退出」。

> 页面上的按钮消失，只是「不让误点」。真正的拦截在后端——手敲地址也进不去不该进的页面。

### 2.3 权限速查（能做什么 / 不能做什么）

| 事项 | 民警 | 领导 / 管理员 |
|---|---|---|
| 看到自己的案件、待办 | ✅ | ✅ |
| 看到全所案件 | ❌ | ✅ |
| 建案、编辑、删除案件 | ❌ | ✅ |
| 指派 / 改派承办人 | ❌ | ✅ |
| 办结 / 撤销案件 | ❌ | ✅ |
| 添加待办、写领导意见、移除意见 | ❌ | ✅ |
| 调整待办的紧急/重点程度 | ❌（只读） | ✅ |
| 提交反馈说明 | ✅ | ❌（领导是「查看反馈」） |
| 勾选待办完成 | ✅（需是本案承办人） | ✅ |
| 撤销（取消勾选）已完成待办 | ❌ | ✅ |
| 添加/编辑/删除子任务 | ✅ | ✅ |
| 标重点关注、只看重点 | ❌（连星标列都看不到） | ✅ |
| 批注：写/改/删 | ❌ | ✅ |
| 批注：看 | ✅ | ✅ |
| 办案阶段流转（转入下一阶段） | ❌（只显示提示） | ✅ |
| 登记/变更强制措施 | ❌ | ✅ |
| 同意终结 / 退回补侦 | ❌ | ✅ |
| 撤回操作（含 Ctrl+Z） | ❌ | ✅ |
| 账号/员工/类别管理 | ❌ | 仅系统管理员 |

### 2.4 有三件事只有「本案现职承办人本人」能做

这三件事领导也代劳不了（系统按承办关系判定，与角色无关）：

1. **开始侦查** —— 必须是主办人本人点。不是本人的时候，按钮位置会显示灰字「由办案人本人点击开始侦查」。
2. **勾选待办完成** —— 需是本案现职承办人，或管理层。非承办人点了会得到提示「只有案件承办人或管理层可以勾选待办完成」。
3. **提交反馈说明** —— 同上。

> 为什么按钮不直接藏起来？藏了会让人以为系统坏了。给明确提示更能帮你判断问题在哪。

## 第 3 章 案件类型：首次使用必做的三步

系统按「刑事 / 行政 / 其他」三类分别管理案件。第一次用要先选类型，否则相关栏目进不去。

### 3.1 三级浏览

```
第1步  选案件大类  →  刑事案件 / 行政案件 / 其他案件
        （卡片上直接显示「共 N 件」，选之前就能看到规模）
第2步  选案件小类  →  卡片列表 + 「未分类」
        （案件管理、案件盯办 才分小类）
第3步  进入栏目    →  案件管理 / 案件盯办 / 待办总览 / 到期提醒
```

**未选类型时点这 4 个菜单**，系统会先把你送到类型选择页，选完**直接回到你本来想去的栏目**（筛选条件不会丢）。

三个大类：

| 大类 | 说明 |
|---|---|
| **刑事案件**（红） | 初查 / 刑拘在办 / 取保及监居 |
| **行政案件**（黄） | 呈批材料 / 行政处罚 |
| **其他案件**（灰） | 未立案及其他非刑事、非行政案件 |

### 3.2 类型条的三个按钮

顶部第二行是案件类型条，右侧按钮随层级变化：

| 你在哪一层 | 左侧显示 | 右侧按钮 |
|---|---|---|
| 第 1 层（大类页） | 选择案件大类 | **退出类型** |
| 第 2 层（小类页） | 选择小类 | **返回大类** |
| 第 3 层（栏目页） | 当前案件类型 | **返回类别** |

### 3.3 三条要记住的规则

1. **切换侧栏栏目不丢选择**，刷新页面也不丢。
2. **点右上角「退出」（退出登录）会清空类型选择**，下次登录重新选。系统不会把你上一个人的类型继承过来。
3. **筛选、统计、图表全部锁定在当前类型内**，所以「列表 20 条、图表总数 200」这种不一致不会出现。

## 第 4 章 民警日常：我的案件 / 我的待办 / 到期提醒

### 4.1 每次登录先看「欢迎回来」

民警登录后自动弹出 4 张汇总卡片，告诉你今天要干什么：

| 卡片 | 含义 | 点进去是 |
|---|---|---|
| **今日需完成**（蓝） | 今天到期的待办 | 我的待办（按紧急排序） |
| **即将超期**（橙） | 3 天内到期或已超期 | 我的待办（按截止排序） |
| **已超期**（红） | 需要立即处理 | 我的待办（按截止排序） |
| **新增领导意见**（灰蓝） | 领导提了意见等你反馈 | **直接打开意见收件箱**（不跳页） |

**数字为 0 的卡片会变淡并且点不动**——避免让你以为界面卡住了。

> 侧栏「我的待办」的红点用的是「即将超期」那个数字（含今天到期与已超期），不要再跟「今日需完成」相加，否则同一条会被数两遍。

### 4.2 我的案件（`我的案件`）

**只显示系统按实名匹配到的本人名下案件**（本人主办或协办）。

页面顶部黄色提示条会说明你的范围。如果提示「**当前账号未关联员工档案**」，说明账号还没绑员工档案，暂时只能看到本人录入的案件——请联系管理员在「账号管理」里关联。

**四张可点击卡片**：名下案件 / 在办中 / 已逾期（红）/ 3天内到期（橙）。点卡片自动带上筛选。

**筛选**：关键字（案件名/编号/备注）、办理状态、到期情况、重置。

**表格**：没有重点星标列，没有案件类型列，操作列只有「详情」。**双击行**也能打开详情。

### 4.3 我的待办（`我的待办`）

**待办的来源只有一个：领导意见。** 领导在案件里写一条意见，系统自动给你生成一条待办。你在「我的待办」看到的每一条，都能点标题跳回原案件。

**筛选与排序**：

- 搜索任务标题
- 状态：待办 / 已完成
- **紧急优先 ↑↓** / **重点优先 ↑↓**：点一下切换排序方向，页面下方会常驻说明当前排序规则
- 排序改过后出现「恢复默认排序」（默认 = 紧急降序 › 重点降序 › 截止升序）

**表格列**：任务标题（下面带案件编号·案件名称）、所属部门/来源、紧急程度、重点程度、截止时间、状态。

> **紧急程度和重点程度你能看不能改**——由领导统一设定。已超期的行浅红底。

**整行可点**，跳到「我的案件」并自动打开该案件详情。

### 4.4 到期提醒

按期限分 5 个页签：**已逾期（默认）/ 今天到期 / 3天内 / 7天内 / 未设期限**。

上方两张图：逾期账龄分布、未来 7 天到期量。**点柱体可以直接切换到对应的页签**。

列表最多显示 100 条，按截止时间升序排列，**双击行看详情**。

页面上方有「只看重点」勾选框（仅领导可见，勾上后两张图也只统计重点案件）。

### 4.5 民警的完整干活流程（推荐动作顺序）

```
1. 登录 → 看「欢迎回来」四张卡，先清「已超期」
2. 点某条待办 → 跳到案件详情 → 看清要求
3. 去干活（走访、调证、出材料……）
4. 回到案件详情 → 找到这条待办 → 点「提交反馈」
5. 填：落实状态（完成/进行中/未完成）+ 说明（+ 执行记录）
6. 提交
7. 勾前面的方框 → 选「完成」→ 确认 → 待办标记完成
```

> **注意：反馈和完成是两个动作。** 只提交反馈不会自动勾完成；只勾方框也必须先有反馈说明。系统强制这个顺序，是为了保证每一条完成记录都有据可查。

## 第 5 章 建案：一份完整的新案件怎么录

**入口**：案件管理页右上「新建案件」。

弹窗宽 960px，分 5 个区块，只有前两个和第五个在**编辑**案件时会显示。

### 5.1 区块一：基础信息

| 字段 | 必填 | 说明 |
|---|---|---|
| **案件名称** | ✅ | 最多 120 字，带字数计数 |
| **案件材料** | ❌ | 只能传 1 个，PDF / Word / Excel。**传了会自动识别来源类型**（pdf→PDF、doc/docx/wps→WORD、xls/xlsx/csv→EXCEL），不传就是「手工录入」 |
| **案件分类** | ✅ | 级联选择：先选大类（刑事/行政/未立案），再选小类 |
| 来源类型 | ❌ | 手工录入 / PDF / Word / Excel（上传材料后自动改） |
| 优先级 | ❌ | 特急 / 紧急 / 普通 / 低，默认「普通」 |
| 案件编号 | ❌ | 最多 64 字 |
| **强制措施** | ❌ | 是 / 否 二选一 |
| └ 措施种类 | 选了「是」就必填 | 拘传 / 拘留 / 取保候审 / 监视居住 / 逮捕。**期限在「案件盯办」里登记，系统会按措施类型自动推算届满日** |
| 备注 | ❌ | 2 行，案件要点 |

### 5.2 区块二：重要时间节点（选填，可多个）

案件期限的真源是这里的「时间节点」，系统会自动挑**最近的一个**作为列表里显示的截止期限。

| 控件 | 说明 |
|---|---|
| 节点类型 | 9 项预设：自定义（手动填名称）/ 受案时间 / 立案时间 / 刑事拘留期限届满 / 逮捕期限届满 / 取保候审期限届满 / 监视居住期限届满 / 补充侦查期限届满 / 变更强制措施时间 / 其他 |
| 节点名称 | **只有选「自定义」时才出现**，最多 64 字 |
| 日期 | 只选到天，**提交时自动补 23:59:59**（否则当天零点会被算成已逾期） |
| 提前提醒 | 1 / 2 / 3 / 5 / 7 / 15 / 30 天，可留空表示不提醒 |
| 删除 | 删掉这一行 |

**三个提效技巧**：

1. **在行内按 Enter 直接追加一行**，不用点按钮。
2. **新行会沿用上一行的提醒档位**（连续填几个节点通常提醒天数一样）。
3. **默认提醒档位取你历史最常用的一档**；没有历史默认给 3 天。

底部提示：「列表『截止期限』与到期提醒只认最近的一个节点，其余节点在案件详情里查看。」

没选日期的半行会被跳过，不打断建案。

### 5.3 区块三：嫌疑人（选填，可多个）

每行：姓名（**必填**，未填的行不会提交）/ 性别 / 身份证号 / 联系电话 / 住址 / 删除。

不填也可以，建案后到案件详情里补充。

### 5.4 区块四：待办事项（选填，可多条）

**这是你要自己决定加不加的部分。**

- 默认**折叠**，点「＋ 添加待办」才展开表格（表单很长，不填就不占地方）。
- 展开后是那张熟悉的表格：序号 / 待办内容（必填）/ 截止时间（选填）/ 重要程度 A·B·C。
- **填完一行按 Enter 直接写下一行**，最多 **10 条**。新行沿用上一行的重要程度。
- 截止时间与重要程度不填就按「C 一般」处理。
- 底部有「常用待办」标签，点一下**填进表格第一空行**（不会直接写进数据库——此时建案还没提交，直接落库的话你点「取消」也回不去）。
- 底部显示「已填 N 条」。

> 写下的每一条都会成为承办人的待办，**标记完成前必须先提交反馈说明**。建案后可在案件详情里逐条增删改。

### 5.5 区块五：立即指派（可跳过）

打开「立即指派」开关 → 选承办人 → （选填）填办理要求 → 建案与指派一步完成。

开关关着时不指派（不是「保持不变」，是「不指派」）。

### 5.6 提交与校验

| 情况 | 提示 |
|---|---|
| 案件名称空 | 请填写案件名称 |
| 未选案件分类 | 请选择案件类型（案件分类） |
| 强制措施选了「是」但没选种类 | 请选择采取的强制措施 |
| 待办超过 10 条 | 待办一次最多 10 条，请删掉多余的再提交 |

成功后提示：`案件已创建，并生成 N 条待办`（带待办时）。

### 5.7 编辑案件时有什么不同

- 标题变「编辑案件」，按钮变「保存」。
- **时间节点、嫌疑人、待办三个区块整块隐藏**（只在新建时填）。
- 强制措施会回显盯办模块登记过的值。

## 第 6 章 指派：把案子交到人手上，顺手把事派下去

**入口**：各列表表格里的「指派」按钮（工作台的待指派/已逾期面板、案件管理、到期提醒）。

标题是 `指派：{案件名}`。

### 6.1 四个字段

| 字段 | 必填 | 说明 |
|---|---|---|
| **截止期限** | ❌ | 选到天，提交时补 23:59:59。右侧会显示「原期限 2026-10-20」或「当前未设期限」。**不改就留空，保持原值** |
| **指派要求** | ❌ | 2 行，办理要求 / 注意事项 |
| **待办事项** | ❌ | 见 6.3 |
| **承办人** | **✅ 至少一名** | 见 6.2 |

### 6.2 怎么选承办人

弹窗里有承办人选择器，两个页签：

**① 检索（默认）**

- 输入姓名/工号/部门/职务，**输入即自动搜索**（也可回车）
- 结果表每行有：**姓名 / 部门·职务 / 归属链路 / 在手 / 「主办」「协办」两个按钮**
- 「在手」数字是这个人当前手上的案件数，大于 0 显示橙色

**② 组织树**

- 顶部「过滤组织树」可实时过滤
- 每个节点右侧也有「主办」「协办」小按钮

**底部「已选」区**：主办（红标签，可 × 取消）、协办（可逐个取消）。

**互斥规则**：

- 点「主办」→ 这个人自动从协办里移除
- 点某个已经是主办的人的「协办」→ 自动取消他的主办身份

**刑拘案件的组别限制**：

案件是「刑拘在办」时，只能指派给**清案组**或**不限**的人。**不符合的人会置灰**（不是隐藏），并显示「只能由清案组人员承办」。置灰是故意的——隐藏会让人以为系统里没别人、以为流程走不通。

### 6.3 待办事项（可跳过）

与案件详情、 建案弹窗里**完全同一套表格**：

- 序号 / 待办内容（必填，最多 500 字）/ 截止时间（选填）/ 重要程度 A·B·C
- **按 Enter 续行**，最多 **10 条**，新行沿用上一行重要程度
- 底部「常用待办」标签，点一下填进第一空行
- 底部显示「已填 N 条」

> **这是「只追加」，不是编辑清单。** 案件里已有的待办**不在这里列出**让你删。要改已有的待办，去 **案件详情 → 案件待办**。理由是：待办带反馈、佐证和办案阶段，删除必须走那条有日志可撤的路。

有常用待办时，底部按钮文案变成 `确认指派（含 N 条待办）`。

### 6.4 提交与提示

| 情况 | 提示 |
|---|---|
| 主办协办都没选 | 请至少选择一名承办人 |
| 待办超过 10 条 | 一次最多添加 10 条待办，请删掉多余的再提交 |
| 案件已办结/已撤销 | 已办结/已撤销的案件不能再指派 |
| 组别不匹配 | 「清案组」案件只能指派给清案组或「不限」人员；XXX 属于「初查组」 |

成功提示会组合：例如 `指派成功，期限设为 2026-10-20，已一并添加 3 条待办`。

## 第 7 章 领导意见与待办：本系统的核心协作机制

这是整个系统的骨架，值得完整读一遍。

### 7.1 一条待办的产生

```
领导在案件详情里写一条意见（内容 + 可选截止时间 + A/B/C）
        ↓
系统存成「领导意见」
        ↓ 自动
派生一条「案件待办」交给承办人
        ↓
承办人干活 → 提交反馈 → 勾选完成
```

**关键**：待办**不是**独立录进去的东西，它一定挂着一条意见。这条链路上内容、截止时间、A/B/C 全部带过去。案件详情、指派弹窗、建案弹窗三个入口走的是同一条链路，产出的数据一字不差。

### 7.2 三处录入，同一张表格

| 入口 | 谁用 | 常用待办标签点一下会 |
|---|---|---|
| 案件详情 → 案件待办 → ＋添加 | 领导 | **直接存进库** |
| 指派弹窗 | 领导 | 填进表格第一空行 |
| 建案弹窗 | 领导 | 填进表格第一空行 |

（案件详情那个是「立即加一条」的用法，主操作就是添加，所以点标签直接落库；另两处主操作是提交整个表单，先填进表格更安全。）

表格本身完全一样：

```
序号 │ 待办内容（必填）        │ 截止时间（选填） │ 重要程度 │ 🗑
 1   │ 走访三名证人             │ 2026-10-15 18:00│   B      │ 🗑
 2   │ 调取银行流水             │                 │   B      │ 🗑
 3   │ 出具情况说明             │                 │   A      │ 🗑
                              ＋ 再添一条   已填 3 条
        重要程度：A 最重要 · B 重要 · C 一般
```

交互规则：

| 操作 | 行为 |
|---|---|
| 内容框按 **Enter** | 光标跳到下一行；已在最后一行则**追加新行**（到 10 条为止） |
| 新行 | **沿用上一行**的重要程度 |
| 只剩一行时点删除 | 把这一行清空（不会把整个表格删掉） |
| 留空不填的行 | 提交时**自动跳过**，不打断 |
| 一次上限 | **10 条** |

### 7.3 常用待办记忆

底部「常用待办」标签区是**按人记**的：系统统计**你自己**最常写的待办，按次数排序，最多显示 8 条，用过多次的带次数角标。

- 新用户没有记录时，这整块不显示。
- 你保存待办后，刚写的内容会进记忆，下次打开就能一键添加。
- 标签只显示你最近用过的那 8 条，不是全部。

### 7.4 待办面板：领导看到什么

案件详情（或盯办抽屉）里的「案件待办」面板：

**顶部**：进度条 + 「已完成 N / M 项」+ 三色紧急性统计（已逾期 n / 临期 n / 正常 n，临期的判定是「距截止 48 小时内」实时算的）。

**每条待办一张卡片**：

| 元素 | 内容 |
|---|---|
| 勾选框 | 完成的主开关 |
| 序号 + 内容 | 加粗；已完成显示灰字删除线 |
| 状态徽章 | 已完成（绿）／意见派生：`反馈状态` + `A/B/C 级` + 紧急性 |
| 元信息 | 「XXX 提出 · 时间 · 截止时间」；已完成显示「完成人 · 完成时间」 |
| 子任务胶囊 | `子任务 N/M`，点开就地展开 |
| 意见设置行 | **仅领导 + 未完成**：就地改截止时间与 A/B/C，改完立即同步回意见 |
| 右侧竖排按钮 | 见下 |

**领导可用的按钮**（右侧竖排）：

- **详情·子任务** —— 看这条待办的全貌
- **查看反馈** —— 看承办人交上来的反馈记录。**反馈是承办人的汇报，领导只查阅不代提交**
- **子任务** —— 展开子任务区并聚焦输入框
- **管理 ▾** —— 下拉菜单：编辑内容 / 上移 / 下移 / 移除意见（连带待办）

**拖拽排序**：桌面端每条左侧有 `⋮⋮` 把手，直接拖。手机端用「管理」里的上移/下移。

### 7.5 待办面板：民警看到什么

同样是这张卡片，操作按钮变了：

- **详情·子任务** —— 看细节
- **提交反馈** —— 打开反馈弹窗（这是干活的人的主要动作，给独立大按钮）
- **子任务** —— 展开并添加子任务

**没有**意见设置行、**没有**管理菜单、**没有**拖拽把手、紧急/重点程度只读。

### 7.6 完成一条待办的完整流程（含两个硬规则）

**两条硬规则（系统强制）**：

1. **子任务必须全部勾完**，才能勾主任务
2. **主任务至少要有一条反馈说明**，才能勾选完成

不满足时勾选框点不动，卡片内会出现橙底说明（不是悬浮提示，不会挡住旁边按钮）：

- 「还有 N 个子任务未完成，全部完成后才能勾选」
- 「需先提交一条反馈说明，才能勾选完成」

**满足条件后**，点勾选框会弹出「标记完成」弹窗：

| 字段 | 必填 | 说明 |
|---|---|---|
| **落实状态** | ✅ | 完成 / 进行中 / 未完成 |
| 落实说明 | ❌ | 最多 600 字 |
| 执行记录 | ❌ | 三要素组合，见下 |

**执行记录**（选填，虚线框）会拼成一句话：

```
请输入：于 [时间]（不选则默认当前时间，精确到秒）在 [系统/平台名称] 执行了 [操作名称] 操作。
```

常用系统有快捷链接可直接点填：一体化办案平台 / 全国公安信息平台 / 电子卷宗系统 / 执法办案系统。

**校验**：

| 情况 | 提示 |
|---|---|
| 平台与操作只填了一个 | 请填写完整的执行平台与操作名称，或两项都留空 |
| 说明与执行记录都空 | 请填写落实说明或执行记录 |
| 未选落实状态 | 请选择落实状态 |

**关键规则**：按你在弹窗里**实际选的落实状态**分派——

- 选「完成」→ 真正标记完成，提示「已标记完成」
- 选「进行中」/「未完成」→ **只记反馈，不动完成状态**，提示「反馈已记录（未标记完成）」

**撤销完成（取消勾选）只有领导能做**，提示「已撤销完成」。

### 7.7 子任务

把一条大待办拆成几个小步骤。

**添加**：卡片上点「子任务」展开，就地有输入框和「添加子任务」按钮，或在「详情·子任务」浮窗里加。上限 **50 个**，**民警与领导都能加**（子任务是干活的人自己拆的）。

**勾完成**：与主任务同一套汇报流程（同样要先有反馈说明）。**不能在列表里直接勾掉**，要进浮窗勾。

**编辑**：浮窗里点「编辑」变输入框，回车保存、Esc 放弃。内容没变则静默取消。

**删除**：二次确认。**已完成的也能删**（删掉即从主任务的完成条件里移除）。

**子任务不能再加子任务**，系统只支持两级。

### 7.8 领导的管理动作

| 动作 | 效果 |
|---|---|
| **编辑内容** | 只改文本，不动已登记的截止时间（批量改内容没有意义，也不该顺手改掉已登记的期限） |
| **上移 / 下移** | 调整意见顺序 |
| **拖拽把手** | 直接拖动排序，序号立刻重算 |
| **移除意见（连带待办）** | 二次确认「『XXX』及其派生待办会一起删除」，成功后提示「意见已移除」 |
| **意见设置行** | 就地改截止时间与 A/B/C |
| **撤销完成** | 把已完成的待办退回未完成 |

> **注意**：意见可以「移除」，但**已登记的反馈记录不会被抹掉**——它是办案留痕。

## 第 8 章 办案阶段：初查 → 刑拘 → 取保的推进

**位置**：案件盯办 → 侦查详情抽屉 → 「办案阶段」面板。案件盯办列表里也有一列显示阶段与进度。

### 8.1 四个阶段

| 阶段 | 颜色 | 含义 |
|---|---|---|
| **初查** | 蓝 | 初查阶段。本阶段待办办完后可转入刑拘在办 |
| **刑拘在办** | 橙 | 刑事拘留办理中 |
| **取保及监居** | 灰蓝 | 取保候审 / 监视居住执行 |
| **已终结** | 绿 | 案件办理完毕 |

### 8.2 进度怎么算

**阶段任务就是案件待办**，系统不再维护第二套清单。

```
阶段进度 = 本阶段「已完成」的待办数 ÷ 本阶段待办总数
```

- 分母只算**本阶段**的待办、只算**顶层主任务**、排除已取消的
- 本阶段没有待办时显示「本阶段暂无待办」，**不显示 100%**（空阶段不该提示「可以流转了」）
- 每次打开实时算，不落库
- 流转到下一阶段后，新阶段待办为 0，进度自然归零

列表里这一列显示：阶段标签 + 进度条 + 已完成数/总数；本阶段待办全办完但还没流转时，额外显示橙色标签「待确认流转」。

### 8.3 流转：做完不自动跳，必须领导点确认

这是**有意设计**：转入哪一阶段是人的决定，不是系统的。

| 情况 | 显示 | 谁能点 |
|---|---|---|
| 本阶段没做完 | 「转入下一阶段」（只有一个出口时是按钮，多个出口时是下拉） | 仅领导 |
| 本阶段做完了 | 「待办已办完，确认转入」（蓝色主色按钮） | 仅领导 |
| 做完了但你不是领导 | 橙色标签「待办已办完」+ 灰字「待领导确认转入」 | — |
| 阶段没有下一站（如已终结） | 不显示 | — |

> **没做完也允许提前流转**（现实中确实存在提前转段的情况）。按钮的提示里会写明「本阶段还有 N 项待办未完成，也可提前转入下一阶段」。

民警点了会被后端拒绝，提示「阶段流转需领导确认」。

### 8.4 流转确认弹窗

标题「确认转入「XXX」」，里面**先说清这一步会改什么**：

1. 案件阶段由「当前阶段」变为「目标阶段」
2. （未做完时）本阶段尚有 N 项待办未完成，转入后不再计入进度
3. **本阶段已办完的 N 项待办保留在案件里，作为办案留痕**（流转不会删旧待办）
4. 强制措施的联动变化，例如：
   - 转入「刑拘在办」→ 强制措施登记为「**拘留**」，案件自动归入刑拘在办板块；并提示「本阶段要求承办人为清案组或不限，**现有承办人可能不再符合，需重新指派**」
   - 转入「取保及监居」→ 强制措施登记为「**取保候审**」

确认后提示「已转入「XXX」」。

### 8.5 可用的流转出口

| 当前阶段 | 可以转到 |
|---|---|
| 初查 | 刑拘在办（刑拘）、批准行政处罚、解除收案 |
| 刑拘在办 | 取保及监居（取保候审）、逮捕、释放、解除收案 |
| 取保及监居 | 解除收案 |
| 已终结 | 无 |

非法动作会被拒：「当前阶段不支持「XX」这个流转动作」。

## 第 9 章 案件盯办：强制措施、侦查进度、审批

**入口**：案件管理 → 案件管理里的「案件盯办」菜单，或从案件详情进入。

### 9.1 页面结构

**四张看板卡**（各带副指标，有风险项时变红）：

| 卡片 | 副指标 |
|---|---|
| 初查案件 | 计划逾期 / 有嫌疑人 |
| 刑拘在办 | 临期 / 超期 |
| 取保及监居 | 30 天内到期 |
| 待审批 | 滞留 ≥2 天 |

点卡片切到对应页签。

**三张图表**（与卡片同源同口径）：在办案件构成（环形，点色块切页签）、措施期限分布、各小类案件数（点条筛该类）。

**三个页签**：初查案件 / 刑拘在办 / 取保及监居。

**检索**（随页签变化）：只看重点、关键字、案件分类（仅初查）、嫌疑人姓名（仅初查）、身份证号（仅初查）、经办人、侦查进度、重置。

**表格**里有价值的几列：

| 列 | 内容 |
|---|---|
| **办案阶段** | 阶段标签 + **进度条** + 已完成数/总数；无待办显示「暂无待办」；待确认流转追加橙标签 |
| **预警** | 优先级：计划逾期N（红）> 措施超期（红）> 措施临期（橙）> 「—」 |
| 侦查状态 | 待初查 / 侦查中 / 待审批 / 侦查终结；无值显示「未开始」 |
| 措施期限 | 措施标签 + 期限文字；无措施显示「—」 |

### 9.2 侦查详情抽屉

点「侦查详情」打开（宽 620px），从上到下四块：

**① 顶部**：案件名 + 侦查状态 + 强制措施 + 流转按钮组（见下）

**② 主办人与盯办人**：现役承办人（主办/协办标签）。**点姓名可以看这个人的承办负荷**（主办数、协办数、已超期、3 天内到期、逐案明细），点明细行可以就地打开案件详情。

**③ 强制措施与期限**：措施名 + 采取日期 + 期限届满（剩 N 天 / 已超期 N 天 / 未登记期限）。**「登记 / 变更」按钮仅管理层。**

登记弹窗：

| 字段 | 必填 | 说明 |
|---|---|---|
| 措施类型 | ✅ | 无（回到初查）/ 拘传 / 拘留 / 取保候审 / 监视居住 / 逮捕 |
| 措施日期 | 选「无」时禁用 | |
| 期限届满 | 选「无」时禁用 | 留空按默认推算：拘留 +30 天 / 逮捕 +2 月 / 取保 +12 月 / 监居 +6 月 |
| 备注 | ❌ | 200 字 |

**④ 办案阶段 + 案件待办**：与案件详情里是同一套组件。

### 9.3 侦查进度流转（四个按钮）

| 按钮 | 谁能点 | 什么时候出现 | 点了会怎样 |
|---|---|---|---|
| **开始侦查** | **仅本案现职承办人本人** | 侦查进度为空或「待初查」 | 进入「侦查中」。不是本人的时候这里显示灰字「由办案人本人点击开始侦查」 |
| **提请审批** | 承办人 | 侦查中 | 进入「待审批」。**至少完成 1 条侦查计划后才能提请** |
| **同意终结** | 仅领导 | 待审批 | 弹审批意见弹窗（意见**选填**） |
| **退回补侦** | 仅领导 | 待审批 | 弹审批意见弹窗，**意见必填**，否则提示「退回补侦必须填写意见」 |

相关提示：

- 未指派主办人就点开始侦查 → 「请先指派主办人再开始侦查」
- 没有侦查计划就提请审批 → 「至少完成 1 条侦查计划后才能提请审批」

## 第 10 章 重点关注：四个栏目里的金色星标

### 10.1 是什么

领导手动标的「必须盯住的那批」案件。**优先于系统按规则算出来的逾期**——所以工作台上的「重点案件」面板排在逾期/待指派**之前**。

### 10.2 怎么标

在列表里**直接点星标**，不用打开案件详情。四个栏目都有：案件管理、案件盯办、待办总览、到期提醒；案件详情抽屉头部也有。

标记后**只改这一行**，不刷新整表——点个星不该让页面跳动。

视觉标识：行首**金色左条** + 金色高亮（与逾期整行标红不冲突）。

### 10.3 谁能用

**仅管理层。** 普通民警**连星标列都看不到**——给他一个永远筛不出东西的勾选框只是添乱。

### 10.4 「只看重点」开关

在案件管理、案件盯办、待办总览里，它是筛选条**最左边**的金色胶囊按钮（选中时整片镀金）；到期提醒没有检索条，所以是页面顶部独占一行的勾选框。

**勾上之后，列表、图表、看板、汇总卡片会一起刷新**，口径完全一致。不会出现「卡片 21 件、列表 2 条」。

从工作台点「重点案件」跳过来时，筛选会自动勾好。

## 第 11 章 信箱与意见收件箱：不会错过派给你的事

### 11.1 通知铃铛（所有人都有）

顶栏铃铛 + 未读角标（超 99 显示 `99+`）。点开是 380px 下拉面板，两个页签：**未读 N** / **已读 N**。

每条信件：类型圆点（意见=红、指派=蓝、状态=橙、待办=绿、疑问=紫）、标题、类型标签、内容两行截断、时间。**底部常驻「查看案件 →」**（项目统一不用悬浮提示，因为悬浮在长列表里基本没人找得到）。

**点一条会发生什么**：

```
标为已读（从未读挪到已读）
  → 自动跳到对应案件：
     领导 → 案件管理并打开该案详情
     民警 → 我的案件并打开该案详情
  → 如果这封信指向某条具体待办/子任务，直接打开任务详情浮窗并高亮 2.6 秒
```

**已读的历史保留在「已读」页签里**，随时能翻。

> 范围差异：领导能看到全所所有人的操作（除自己的）；民警只收到与自己承办案件相关的。

### 11.2 意见收件箱（民警的专属入口）

欢迎弹窗的「新增领导意见」卡片点开就是它（**在当前页直接打开，不跳走**），也可以从别处触发。

邮件式交互，**两步**：

1. **点开一条** → 展开全文，同时记为已读（但**暂不从列表消失**，灰显着让你读完）
2. **点「知道了」或「去处理」** → 这条才从列表去掉

> 两步是有意的：「看」和「看完」是两个时刻，读一半就消失会打断阅读。

每条显示：案号（缺省显示「案件#ID」）+ 案件名 + 重要程度彩色标签（A·最重要 / B·重要 / C·一般）+ 紧急性 + 摘要（收起两行截断）+ 提出人·时间 + 落实期限。

展开后有两个按钮：

- **去处理** → 跳到该案详情
- **知道了** → 归档移除

底部提示：「点开即记为已读；需要落实的在案件详情里反馈」。

全部读完时显示「已全部读完」。

**重要**：领导新提意见后会立即出现在这里；你**在案件详情里提交了对这条意见的反馈，它会自动标记已读**，不用再来这里手动清。

## 第 12 章 操作记录与撤回：点错了怎么办

### 12.1 在哪看

**工作台右下角「最近操作」面板**，两个页签：**案件相关** / **其他操作**（登录记录很频繁，分开才不会被挤掉）。点任一条打开操作详情抽屉。

**案件详情 → 办理进度**（仅领导），默认收起，点开看完整时间线。

### 12.2 撤回的两种方式

| 方式 | 怎么做 | 限制 |
|---|---|---|
| **撤回上一步** | 工作台面板右上按钮，或按 **Ctrl+Z**（Mac 是 Cmd+Z） | 仅领导；无可撤回项时按钮置灰 |
| **撤回此操作** | 操作详情抽屉底部 | 仅领导，仅 `可撤回` 的条目 |

> Ctrl+Z 在输入框、文本域、下拉框里**不会触发**（文本撤销优先）。

### 12.3 撤回确认弹窗

「撤回上一步」：

> 标题「撤回上一步（Ctrl+Z）」，内容「将撤回最近一步操作，相关数据回到操作前：【操作名】内容」，按钮「确认撤回」/「取消」

「撤回此操作」：

> 「将把这一步操作撤销，相关数据回到操作之前的状态（涉及 N 项变更）。**撤回本身也会记入操作记录，可以再撤回一次做恢复**。」

成功后自动打开撤回记录的详情抽屉，让人看清回滚成了什么。

### 12.4 操作详情抽屉里有什么

- 顶部：操作类型彩色标签 + 状态（已被撤回 / 可撤回 / 不可撤回时显示后端给的原因）
- 描述表：操作时间 / 操作人（无则「系统」）/ 操作类型 / **涉及案件**（可点跳详情）/ **撤回的对象**
- **变更明细表**（字段 / 变更前 / 变更后）：空值显示「—」；没有变更时显示「这次操作没有产生字段变化」
- 底部：关闭 + 撤回此操作

非领导看到的是灰字「撤回需要所长 / 副所长 / 法制员权限」。

### 12.5 撤回的规则（重要）

1. **只能撤回最新一步。** 一旦发生了一次撤回，更早的日志就无法再撤了。
2. **有些操作不能撤回**（界面上会显示不可撤回及原因）。意见/待办类可撤回的操作：添加意见、编辑内容、改属性、移除意见、添加待办、编辑待办、删除待办、标记完成、撤销完成、提交反馈、添加子任务、撤销子任务完成。
3. **批注（COMMENT_*）与领导意见的落实反馈不进撤回体系**——它们是旁注语义，不是流程步骤。
4. 办案阶段流转有意**不进**可撤回白名单（快照还原不回整套任务集合）。

### 12.6 批注

类比 Word 批注，挂在办理进度的每一步下方。米黄底 + 橙色左竖线。

- **写/改/删仅领导**，读所有人可见。
- 入口：时间线上每一步底部的「批注」/「追加批注」按钮（仅领导，且该步未撤回）。
- 空内容 → 「请填写批注内容」。

## 第 13 章 系统管理员：账号管理 / 员工图谱 / 类别管理

### 13.1 账号管理（`账号管理`）

侧栏带红点＝有待审核的注册申请，**默认停在「待审核」页签**。

**表格列**：登录名 / 姓名 / 角色 / 部门 / 手机号 / **关联员工** / 状态 / 注册时间 / 操作。

「关联员工」这一列会暴露问题：

- 绿色正常显示姓名
- 橙色「**自建**」标签＝这条员工档案是申请人注册时自己建的，需要核对
- 红色「**未关联**」标签＝升级前的老账号，需要补绑

**审核通过**：

弹窗里申请人信息只读显示，需要你确认并选择：

- **角色**（必填）
- **关联员工**（必填）——远程搜索下拉，占用中的员工不会出现在候选里
- 办案组别（**角色为普通民警时必填**）
- 备注（审核意见，选填）

如果申请人自建过档案，会显示黄色警示条「该员工档案由申请人注册时自行建立，请核对姓名与部门无误后再通过」。

也可以就地「**＋ 新建员工档案**」，不必跳出去先去员工图谱建人。默认预填姓名、职务默认「组员」。

**其他操作**：

| 操作 | 说明 |
|---|---|
| 驳回 | 必须填驳回原因（会展示给申请人） |
| 编辑 | 留空「关联员工」＝**不改绑**（不能解绑） |
| 重置密码 | 新密码至少 6 位。重置后该账号全部端都被踢下线 |
| 停用/启用 | 停用后无法登录 |
| 删除 | 不可恢复 |

**系统保护**（不可绕过）：

- 不能修改自己的角色（避免把自己锁在门外）
- 不能停用当前登录的账号
- 不能删除当前登录的账号
- 员工标记为离职/停用时不能关联账号

**校验提示**：

| 情况 | 提示 |
|---|---|
| 民警未选组别 | 请选择办案组别 |
| 未选角色 | 请选择角色 |
| 登录名 < 3 | 登录名至少 3 个字符 |
| 密码 < 6 位 | 密码至少 6 位 |
| 既没选员工也没建档案 | 请为账号关联一名员工：在「关联员工」中检索选择，或点「新建员工档案」现场建立 |

### 13.2 员工图谱（`员工图谱`）

**左栏：组织树**

两种视图：**列表** / **树状图**。

- 列表：可按姓名/部门/职务过滤，树默认全展开。每行有色点（按层级）、姓名、职务、部门、【部门待核】橙色旗标、「在手 N」（>0 时橙色）。
- 树状图：自上而下树形，节点圆点按职务层级取色（部门待核一律橙色）。可拖拽平移、滚轮缩放、点圆点展开收起。
- 层级图例常驻在下方（领导/副领导/组长/组员 + 部门待核）。

底部概括：「共 N 人 · N 级组织 · N 个部门」。

**右栏：员工详情 / 编辑**

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 工号 | 导入时的唯一标识 |
| **上级** | **只给「恰好高一层」的人**（总-副总-组长-员工）。会实时提示候选名单 |
| 部门 | 可搜索可新建，显示「XX（N人）」 |
| **职务** | 领导 / 副领导 / 组长 / 组员（可新建）。**职务决定组织层级**，下方实时显示 |
| **办案组别** | 初查组 / 清案组 / 不限 |
| 手机 / 邮箱 / 排序 | 排序 0 起，越小越靠前 |

非管理员只能看不能改。上级不能设成自己的下级（会形成环）。

下半区「在手案件」：按期限升序，排除已办结/已撤销，取 20 条。

**Excel 导入**：

1. 点「下载导入模板」
2. 填好后点「Excel 导入」，**只支持 .xls / .xlsx / .csv**
3. 成功提示「导入完成：成功 N 条 / 共 M 条」
4. 有修正时会列出**前 10 条**错误

**底部两张图**：部门在手案件负载、个人在手负载。超 8 人时会显示「列出 N 人 · 可上下滑动」，点柱体跳到该人/部门的案件列表。

### 13.3 类别管理（`类别管理`）

维护各大类下的小类（案由）。**改完立刻生效**，案件管理与盯办的「案件分类」级联选择立即拿到最新分类树。

- 筛选：全部 / 刑事 / 行政 / 未立案
- 表格：所属大类 / 小类名称 / 排序 / 操作
- 新增编辑：大类（必填）、小类名称（必填，64 字）、排序（0~999，越小越靠前）
- 删除确认：「确定删除小类「XXX」吗？**已有案件上保留的小类文字不受影响，仅从选择器移除**。」
- **未立案不设小类**

## 第 14 章 常见问题

### 14.1 我怎么才能看到某个案子

按顺序检查：

1. 你是不是**主办或协办**？（民警只看自己名下的案件）
2. 你的账号**有没有关联员工档案**？没关联就只能看到本人录入的
3. 是不是被**案件类型门控**挡了？（先选类型）
4. 是不是被**小类筛选**挡了？（在类型条上逐级退回）
5. 是不是勾了**「只看重点」**？（重置按钮会一起清掉）

### 14.2 为什么我点某个菜单没反应 / 页面被弹回来

- **民警点了工作台、案件管理、案件盯办、待办总览** → 会回到「我的案件」。这是设计：民警只开放 4 个页面（我的案件、我的待办、到期提醒、案件类型选择）。
- **领导点了员工图谱 / 类别管理 / 账号管理** → 回到工作台。这三项仅系统管理员可见。
- **选完类型又被弹回、菜单像点不动** → 报告这个情况，属异常。

### 14.3 为什么勾选框点不动

橘色说明条已经告诉你原因：

| 说明 | 怎么办 |
|---|---|
| 还有 N 个子任务未完成，全部完成后才能勾选 | 先把子任务逐个勾完 |
| 需先提交一条反馈说明，才能勾选完成 | 点「提交反馈」写一条 |

### 14.4 我提交了反馈，为什么待办还是「待办」

因为你在反馈弹窗里选的落实状态是**进行中**或**未完成**。系统按你实际选的状态分派：只有选「完成」才会标记完成。

想完成就再勾一次方框，这次选「完成」。

### 14.5 为什么我找不到「办结」「删除」「指派」按钮

- 办结、删除、指派、标重点：**仅管理层**
- 办理进度时间线：**仅管理层**
- 提交反馈：仅民警（领导看的是「查看反馈」）

### 14.6 案件怎么一直显示「待指派」

案件状态是唯一的，但**推进状态必须走唯一的合法入口**——不能靠编辑案件表单改（编辑任何在办案件都会把它打回「待指派」）。用案件详情底部的「开始处理」/「办结」，或列表的「指派」。

### 14.7 列表里「截止期限」跟我填的节点不一样

系统**自动取最近的一个未过期节点**作为列表显示的期限（全部过期则取最晚的一个）。其余节点在案件详情里能看到。想换显示的期限，改节点的日期即可。

### 14.8 逾期的判断准吗

准。系统做两件你手工容易漏的事：

1. 选到天的期限**提交时自动补 23:59:59**（否则当天零点就被算逾期）
2. 服务器时间必须与标准时间同步（内网部署时由 IT 保证）

### 14.9 我退出了登录，下一个人登录会看到我的案件类型吗

不会。**点「退出」会清空案件类型选择**，下次登录重新选。

### 14.10 界面上的数字和点进去的条数不一致

不应该出现。如果出现了，这是缺陷，请报告。系统的口径约定是：列表、图表、看板、汇总卡片在同一个类型与小类范围内完全一致。

### 14.11 系统会提醒我吗

**目前不会主动推送提醒。** 到期提醒是「打开页面才计算」。你需要主动看：民警看「我的待办」和工作台卡片，领导看「工作台」和「到期提醒」。

## 附录 A 术语表

| 术语 | 含义 |
|---|---|
| **案件类型** | 刑事 / 行政 / 其他，三级浏览的第一层，决定后面所有栏目的数据范围 |
| **小类 / 案由** | 案件类型下的细分类别，如「电诈」 |
| **办案阶段** | 初查 / 刑拘在办 / 取保及监居 / 已终结。阶段任务**就是**案件待办 |
| **领导意见** | 领导对案件的指示，一定派生一条待办 |

| **主任务 / 子任务** | 待办分两级，子任务不能再有子任务 |
| **反馈说明** | 承办人对待办进展的汇报，标记完成的必要条件 |
| **佐证材料** | 佐证材料就是附件（可多份）。**已完成待办的最后一份佐证禁止删除** |
| **主节点** | 案件时间节点中最近的一个，决定列表显示的截止期限 |
| **强制措施** | 拘传 / 拘留 / 取保候审 / 监视居住 / 逮捕 |
| **办案组别** | 初查组 / 清案组 / 不限，决定员工能接什么活 |
| **重点关注** | 领导手动标的星标，四个栏目统一口径 |
| **现行承办人** | `case_assignee` 里状态为 ACTIVE 的记录。改派后旧记录置为「已改派」留痕 |
| **主办 / 协办** | 一案多人，主办 1 人（唯一），协办若干 |
| **撤回** | 把最近一步操作回滚，数据回到操作之前 |
| **批注** | 挂在办理进度每一步下方的旁注，不进撤回体系 |
| **只追加** | 指派弹窗的待办语义：只新增，不动已有待办 |
