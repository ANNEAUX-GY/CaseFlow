## push 代理坑（已解决）
- 现象：`git push` 报 `CONNECT tunnel failed, response 502`。
- 环境有 http_proxy/https_proxy=http://127.0.0.1:56868；该代理转发 github 首页/api 都 200，
  但 git 自动取用的代理路径有时失败。
- 可用解法：显式 `git -c http.proxy=http://127.0.0.1:56868 -c https.proxy=... push origin main`
  （本次一次成功，d17d6c1..aff1d7b）。ls-remote 同样加 -c 代理参数。
- 注意：curl --noproxy 直连 github.com git 端点不通（000），api.github.com 直连通（200）。
