- `app/scripts/package_deploy.py` **新增 `--patch-only`**：内网更新专用补丁包
  （只有 jar + 升级说明 + 建库语句，**不含 config/ 与 data/**，从物理上断掉"解压全部覆盖"
  把口令打回占位、把空占位塞进 data 的误操作）
- 新增 `app/scripts/verify_upgrade_safe.py`（零依赖，11 项，退出码非 0 即违规）：
  ① schema.sql 无 DROP/TRUNCATE/ALTER/RENAME/MODIFY/DELETE/UPDATE 且全部
  `CREATE TABLE IF NOT EXISTS` ② 迁移只 ADD COLUMN ③ 每次启动的 UPDATE 必须
  `WHERE ... IS NULL` 或位于 `if (onceOnly(...))` 闸门内 ④ `NEW_COLUMNS` 的 90 列
  必须都在 schema.sql（防新装缺列）。**每次出包前跑一遍。**

写这个脚本踩的两个误报坑：① `COMMENT '...DELETE...'` 与外键 `ON DELETE CASCADE`
被当成删数据语句 → 先剥字符串字面量、再把 `ON DELETE/ON UPDATE` 换掉；
② 方法体正则把 `if (` / `for (` 当方法名 → 只认带返回类型的方法声明。
