## 五项需求（commit a07017c）

用户一次性提了 5 项，都已实现、编译通过、接口冒烟验证。

### 1. 案件列表按阶段分两套时间排序
- 初查/行政 → case_time（接报/受理时间）；刑拘在办(DETAIN)/取保在办(BAIL) → measure_date（采取措施时间）。
- 实现：CaseService.buildWrapper 的 case_time 分支改用 `q.last("ORDER BY CASE WHEN flow_stage IN ('DETAIN','BAIL') AND measure_date IS NOT NULL THEN measure_date ELSE case_time END ...")`。
- 用户原话「先做个样出来」，后续若要独立的刑拘时间/取保时间字段再细化。
- 注意：`matchingCaseIds` 也走 buildWrapper，会带上 ORDER BY（对取 id 集合无副作用，仅多一次排序）。

### 2. 民警可给自己经办案件添加待办（当记事本）
- 后端：TodoService.add 的 requireAdmin 改成 checkAdd（管理层 或 本案 ACTIVE 承办人）；
  TodoController.add 去掉 @FullAccessOnly。
- 前端：CaseTodoPanel 给非管理层、非研判员加「＋添加记事」单条录入（走 todoApi.add），
  领导仍走批量提意见（addOpinions）。新增 canAdd computed = isAdmin || !isJudge。

### 3. 研判员 JUDGE 角色（查看全量 + 录入嫌疑人，无管理权限）
- Roles 新增 JUDGE + canViewAllCases()；AuthContext 加 canViewAllCases()/isJudge()。
- CaseService.scopeToSelf 改用 canViewAllCases（研判员不再收敛到本人名下）。
- SuspectService.checkOperate 放行 isJudge。
- 前端：user.js 加 JUDGE_ROLE / isJudge / canViewAllCases；navTierOf 加 JUDGE 档；
  router 加 JUDGE_PAGES 白名单 + fullAccessOnly 放行研判员；NavPanel 加研判员侧栏。

### 4. 队长 CAPTAIN 角色（权限同副所长）
- Roles 加 CAPTAIN，纳入 isFullAccess + APPLICABLE。前端 FULL_ACCESS_ROLES 加 CAPTAIN。

### 5. 工作记录本（侧边栏入口，新表 work_log）
- 后端：WorkLog 实体 + Mapper + Service + Controller（/work-logs），schema.sql 建表 + 二级索引。
- 权限：普通民警只看/写自己（employee_id 强制收敛）；其余角色可检索查看任意民警。
- 前端：WorkLog.vue（列表/新增/编辑/删除/按民警筛选/关键词检索）+ api + 路由 + 侧栏三档入口。
- 归属挂 org_employee.id（员工档案），不挂账号。

## 关键结论 / 坑
- **新表无需进 NEW_COLUMNS**：schema.sql 的 CREATE TABLE IF NOT EXISTS 由 spring.sql.init
  每次启动自动补建（与 case_todo/case_suspect 同款处理）。gen_upgrade_sql 只生成补列 SQL，
  新表靠启动自建，说明文档里写清即可。
- **时间字段被 JacksonConfig 全局截成 yyyy-MM-dd**：work_log.createdAt 出参也是日期，
  符合「时间精度到天」约定，前端用 dateKeyOf 即可。
- **角色下拉统一走 /auth/roles → Roles.applicable()**（不含 BOSS），新增角色加进
  APPLICABLE 即可同时出现在注册页和账号管理页。
- **研判员能被 @FullAccessOnly 正确拦截**（PermissionInterceptor 用 isFullAccess），
  但案件 page/detail 接口没有 @FullAccessOnly，靠 scopeToSelf 收口——这是研判员能看全量的关键。
- **CaseDetailDrawer 的「新增/编辑/删除嫌疑人」按钮没有 v-if**（对所有能打开详情的人显示），
  权限完全靠后端 checkOperate 兜底；研判员放行后即可录入嫌疑人。
