## 修复归属民警下拉 + 警号替代工号 + 档案账号一对一批量建号（commit 13e6f3c）

### 关键 bug 根因（归属民警下拉空数据）
- WorkLog.vue load/loadEmployees 写 `res.data`，但 axios 拦截器（api/index.js 第78-94行）
  已把 `body.code===0` 时 return `body.data`，所以 workLogApi.list/employees 返回的
  **直接就是数组**，`res.data` 恒 undefined → employees/rows 永远空。
- 教训：**凡 API 返回 Result 解包后是数组/对象的，别再加 `.data`**；返回 PageResult
  的（如 caseApi.page）解包后是 `{list,total}`。两种要分清。

- Excel 导入幂等键 employeeNo → policeSystemNo：EmployeeExcelRow 表头「工号/上级工号」
  →「警号/上级警号」，importExcel 用 getPoliceNo()/policeSystemNo 做幂等与 parentNo 匹配。

  默认 title「组员」→「普通民警」。

### 档案-账号一对一 + 批量建号
- 引入 pinyin4j 2.5.1（com.belerweb:pinyin4j:2.5.1，JDK8 兼容）。
  下载命令：`JAVA_HOME=.../jdk8 mvn -Dmaven.repo.local=.../m2repo dependency:resolve -DincludeArtifactIds=pinyin4j`
  （非 -o 离线，联网下载到 tools/m2repo）。
- UserService.batchCreateAccounts()：扫描无账号的在职档案，用户名=姓名拼音（多音字取第一音，
  非中文原样保留，重名加数字后缀）、密码=123456、角色按职务映射。
- 角色映射 roleOfTitle：所长→CHIEF、副所长→DEPUTY_CHIEF、队长/组长→CAPTAIN、
  法制→LAW_OFFICER、案管→CASE_MANAGER、研判/辅判/侦判→JUDGE、系统/管理员→BOSS、其余→STAFF。
- 接口 POST /users/batch-create-accounts（@FullAccessOnly），前端账号管理页加
  「为无账号民警批量建号」按钮。
