### ★ GitHub 通道这次连直连都挂了，做了个隧道工具 ★

现象（与 10-18 那次不同，值得记）：
- 环境 `http_proxy=127.0.0.1:65405`：`curl -x proxy https://github.com` →
  `CONNECT tunnel: HTTP/1.1 502 Bad Gateway`（代理本身活着：百度 200 / 0.5s）
- 剥代理直连：`Failed to connect to github.com:443 after 21068 ms`
- `nslookup github.com` → **20.205.243.166**（该 IP 的 443 直连超时，试 2 次均失败）

关键发现：
- `140.82.112.3 / 140.82.113.3 / 140.82.114.4 / 20.27.177.113` 的 **443 全都通**；
  `curl --resolve github.com:443:140.82.113.3 https://github.com/...` → HTTP 200。
  所以**只是 DNS 解析到坏 IP**，不是整个 GitHub 被挡。
- 本机不是管理员，`hosts` 写不进去（`IsInRole(Administrator)=False`）。
- 于是写 `app/scripts/gh_tunnel.py`：本地 CONNECT 代理，把目标 IP 换掉但
  **保留 SNI/Host 为 github.com**（TLS 正常，不用关 sslVerify，也不改 hosts）。
  用法：先起隧道，再 `git -c http.proxy=http://127.0.0.1:18999 push origin main`。

中途踩的坑：第一版隧道把客户端发来的 **CONNECT 报文本身**也 `write` 给了源站，
`curl` 直接 `exit 35 (SSL connect error)`。CONNECT 报文只给代理看，回完 200 就
**只做字节管道**，一个字节都不能多写。

以后 push 顺序：先直连 → 失败则起 `gh_tunnel.py` → 都别再反复干等。

## 22:22 列宽第三次调整：剩余空间改多列均摊（commit f6ca87d）

用户圈出宽屏下「主办 / 协办」与「截止期限」之间的一大块空白。

**根因**：全表只有主办列是 `min-width`，el-table 的 `fit` 会把**全部**剩余空间
灌给这一列 —— 1600px 下它被拉到 ~290px，表头和数据都左对齐，右半边就是空的。

**定式（记住这条，别再三番五次试）**：
- 想让表格铺满又不出现空列 → **让多列都做 min-width**，剩余空间按比例均摊；
  只有一列是 min-width 时它必然独吞，造出空白。
- 必须固定的列：`案件名称`（用户不希望它随窗口变胖）、`操作`（fixed right，
  宽度漂移会让按钮位置乱跳）、`报案/受案时间`、`重点`。
- 1366px 是基准：各 min-width 之和 + 固定列 = 1080，正好无余量，
  所以 1366 下界面就是 min 值本身，宽屏才等比放大。

当前余额（1366）：重点54 | 时间132 | 名称172 | 类型80 | 嫌疑人88 | 阶段80 |

## 22:56 内网接入问答补充：程序对数据库的权限要求

核查结果（给内网 DBA 用）：
- 启动时**只**做：`CREATE TABLE IF NOT EXISTS`（缺表才建）、`ALTER TABLE ADD COLUMN`
  （缺列才补，全部可空）、`UPDATE ... WHERE 列为 NULL`（只补空值）、
  `CREATE TABLE IF NOT EXISTS schema_migration_mark`（一次性台账）。
- **不建索引、不建视图、不删任何东西、不碰 information_schema / 其它库**。
  索引只在 `app/sql/index-mysql.sql` 里，人工执行一次。
- 授权最小集：`GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER ON case_flow.* TO ...`
  —— **CREATE / ALTER 必须有**，否则首次升级补列失败（程序逐列容错只 WARN，
  但措施审批、到期提醒、案件时间列会因缺列不可用）。不需要 DROP / SUPER / FILE。
- 完整包里 0 个数据库文件（`data/` 只有说明.txt），所以「装之前要清空测试数据」
  这个动作根本不存在。
