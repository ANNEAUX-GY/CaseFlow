# DESIGN.md · CaseFlow 案件指派系统 · 汇报与讲解

> 路线判定：场景属公安机关内网汇报 → 命中「红金政务风」**结构层**（A/B/C/D 分区、中文优先、密度优先、零旋转纪律、卡片规范）；**常量值层**（红金配色）按项目品牌改写为**警蓝 + 警徽金**（软降级命中：结构层完整执行，常量值层由 query 改写）。

## 1. 画布与全局母版（1280×720）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 留白区** | y 0–40 | 40px | 完全留白；禁任何文字/标识 |
| **B · 标题块** | y 40–116 | 76px | 中文主标 34px bold（黑体），左侧 6px 竖色条 + 标题 |
| **C · 内容区** | y 116–664 | 548px | 正文、图表、配图、卡片 |
| **D · 页脚条** | y 664–696 | 32px | 左：项目名灰字；右：页码 `NN / 16`，14px 灰字；底部 6px 警蓝三段装饰条 |

- 页面 padding：左右 64px。
- 封面 / 章节过渡 / 结束页可省略 A/B/D，采用自定义版式；其余内容页严格保持母版一致。
- D 区装饰条比例：`#1B4A8C` 55% + `#2E6BB0` 25% + `#C8A45C` 20%（禁等宽）。

## 2. 颜色系统（4 hex + 中性）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色 警蓝** | `#1B4A8C` | 背景块、标题栏、主视觉底、装饰条主段 |
| **深藏蓝** | `#12294A` | 封面底、深色卡片、文字强调 |
| **辅色 中蓝** | `#2E6BB0` | 卡片头渐变、图表第二系列、分隔条 |
| **强调色 警徽金** | `#C8A45C` | 只用于焦点：巨型数字、关键标签、装饰条末段、印章徽记 |
| 中性浅 | `#F4F6F9` | 卡片浅底 |
| 中性文字 | `#1F2733` | 正文主字 |
| 中性灰 | `#8A94A6` | 脚注、页码、辅助线 |
| 白色 | `#FFFFFF` | 内页主背景 |

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色（警蓝） | ≤ 60% | 背景、大色块、标题栏 |
| 辅色（中蓝） | ≤ 30% | 卡片背景、图表次系列 |
| 强调色（警徽金） | ≤ 10% | 只出现在焦点元素（巨型数字、关键标签） |
| 中性色 | 剩余 | 文本、页脚、边框 |

- **Hero 页**：强调色可到 15%。
- **Supporting 页**：强调色 ≤ 5%。
- 至少 2 页（P01 封面、P09 期限页）色彩比例显著不同于其他页。

### 2.2 渐变与半透明

- 卡片头渐变：`linear-gradient(135deg, #1B4A8C 0%, #2E6BB0 100%)`
- 封面底：`linear-gradient(135deg, #12294A 0%, #1B4A8C 100%)`
- 大面积浅色覆盖：`rgba(27,74,140,0.06)`
- 卡片投影：`0 4px 20px rgba(18,41,74,0.10)`
- 元素重叠：底层 `opacity: 0.15~0.25`

## 3. 字体系统

| 层级 | 字号 | 字重 | 行高 | 字体 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标 | 72 | bold | 1.2 | 黑体 |
| 章节大字（PART 数字） | 96 / 40（中文） | bold | 1.0 / 1.3 | 黑体 |
| 页面主标题（B 区） | 34 | bold | 1.3 | 黑体 |
| 副标题 / 卡片小标 | 24–26 | bold | 1.4 | 黑体 |
| 正文 | 20–22 | regular | 1.6 | 微软雅黑 |
| 巨型数据/锚点 | 84–112 | bold | 1.0 | 黑体 |
| 脚注 / 页码 | 14 | regular | 1.4 | 微软雅黑 |

- 字体家族 ≤ 2 套：标题黑体、正文微软雅黑。
- 巨型数字用比正文更重的字重（bold 100 vs regular 20）。

## 4. 信息密度门禁

- 常规内容页留白 ≤ 35%；封面 / 章节过渡 / 结束页不受限。
- 内容页单主题 ≥ 180 字；卡片组每卡 ≥ 100 字。
- 卡片填充率 ≥ 85%；卡片尾元素 `marginTop: 'auto'` 锚底；兄弟卡尾部 y 差 ≤ 16px。
- 每页 ≥ 1 个视觉锚点（≥ 44px 元素 或 ≥ 40% B 区面积的图）。
