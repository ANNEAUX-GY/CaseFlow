# STORY.md · CaseFlow 案件指派系统 · 汇报与讲解

## ① 用户意图对齐

- **目标受众**：所队领导与办案民警。场合为**内部功能汇报 + 使用讲解**（既是给领导看成果，也是给民警当培训教材）。
- **核心目标**：讲完后，领导认可「这套系统把收案—指派—盯办—办结全链路管起来了，且刑事/行政两套规则都落地了」；民警记住「每天先看红点、待办怎么闭环、办案阶段怎么流转」。
- **PPT 长度**：16 页（Hero 页配额 3–4 页）。
- **视觉调性**：庄重、公安蓝、清晰、信息密度高（政务汇报气质）。
- **内容边界**：必讲——系统定位与全貌、两类案件的分野、盯办、期限、意见-待办闭环、办案阶段流转、权限与追溯、操作讲解（民警日常）；不讲——具体代码实现细节、部署运维命令；不碰——敏感真实案件信息（用演示数据）。

> 风格推导：本系统为**公安机关**内网应用，场景属政务机关汇报 → 命中「红金政务风」的**结构层**（A/B/C/D 分区、中文优先、密度优先、零旋转纪律）；但其**常量值层**（红金配色）与产品身份（警蓝）冲突，按 query 改写为**警蓝 + 警徽金**配色（软降级命中：结构层保留，常量层由项目品牌改写）。

## ② 页面布局骨架

- **页面总数与分章**：16 页，4 章。
  - 第 1 章「系统全貌」：P03 扉页、P04 系统定位、P05 全链路
  - 第 2 章「核心机制」：P06 扉页、P07 两类案件分野、P08 盯办、P09 期限（核心）
  - 第 3 章「协作与治理」：P10 扉页、P11 意见-待办闭环、P12 办案阶段、P13 权限与追溯
  - 第 4 章「使用讲解」：P14 扉页、P15 民警日常、P16 结束
- **目录↔章节扉页契约**：目录声明 4 章 → 全篇恰好 4 个 `type: section` 扉页（P03/P06/P10/P14），编号 01..04 连续、标题逐字一致。
- **Hero 页定位**：P01 封面、P09 期限引擎（核心高潮）、P16 结束页 → 3 页 Hero（19%）；P02 目录、P04、P05、P07、P08、P11、P12、P13、P15 为 supporting；P03/P06/P10/P14 为 transition。
- **rhythm 曲线**：P01 peak → P02 valley → P03 transition → P04 valley → P05 valley → P06 transition → P07 valley → P08 peak → P09 peak → P10 transition → P11 valley → P12 valley → P13 valley → P14 transition → P15 valley → P16 peak。（P05–P07 连续 3 页非同为 valley，P12/P13 连续 2 页后接 transition 打断。）
- **非对称版式预算**：16 页中 ≥40% 用非对称 → 目标 ≥7 页非对称（实际 11 页）。
- **对称版式预算**：全篇仅 P02 目录用对称版式，其余全非对称。
