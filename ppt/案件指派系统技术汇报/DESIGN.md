# DESIGN.md — 案件指派系统技术汇报

> 命中风格：**红金政务风**（党政机关向领导汇报场合）。
> 在该风格 DNA 基础上做一处**主色替换**：系统本体主色为公安警蓝（#1b4a8c），
> 汇报物料沿用警蓝做主视觉、深藏蓝做底、警徽金做点缀——比纯红更贴合公安语境，
> 且与系统实际界面同源，领导看到的颜色与打开系统看到的颜色一致。
> 风格 DNA 其余条款（母版骨架、字体层级、零旋转、密度下限、硬闸门）全部遵守。

## 1. 画布与母版

画布 1280×720，左右 padding 70。

| 区域 | 范围 | 规则 |
|---|---|---|
| A 留白区 | y 0–48 | 完全留白，禁任何文字/标识/SECTION/右上小字 |
| B 标题块 | y 48–110 | 中文主标 34px，宋体 CN Heavy，深藏蓝 `#12294a` |
| C 内容区 | y 110–660 | 正文、图表、卡片、流程图 |
| D 页脚装饰条 | y 660–700 | 底部三段装饰条（警蓝→藏蓝→金），高 10px，可叠页码 `NN / 24` |

D 区三段比例：`#1b4a8c` 52% + `#12294a` 30% + `#c8a45c` 18%；**禁完全等宽**。
封面、目录、6 张章节扉页、结束页可省 A/D；正文页严格遵守。

## 2. 色彩

| 角色 | hex | 用途 |
|---|---|---|
| 主色 警蓝 | `#1b4a8c` | 封面/目录/扉页主底、强调块、装饰条中段 |
| 深藏蓝 | `#12294a` | 内页标题字、美术层深底 |
| 警蓝浅 | `#2a5da6` | 渐变中段、次级强调 |
| 警蓝极浅 | `#e8eff8` | 卡片头底、表格隔行 |
| 警徽金 | `#c8a45c` | 重点数字、细线、锚点圈 |
| 金浅 | `#e8c87c` | 金字高光 |
| 文本 | `#1b2430` / `#5a6472` | 正文主字 / 次字 |
| 白底 | `#FFFFFF` | 内页背景 |
| 语义红 | `#c62a2a` | 逾期、风险项（仅数据/风险场景） |

配色比：美术层藏蓝+警蓝 ≥50%，金 15–25%；内页白 ≥60%，蓝 8–20%，金 ≤5%。

**涨跌不适用**（本汇报无股价/营收数据），语义红绿只用于「逾期/已完成」状态标识。

## 3. 字体

| 用途 | 字体 | 规则 |
|---|---|---|
| 正文/卡片说明 | 微软雅黑 / OPPOSans M | 正文必须无衬线 |
| 内页主标 | 宋体 CN Heavy / Source Han Serif CN Heavy | B 区主标固定 34px |
| 美术大字 | 华文楷体 900W / 宋体 Heavy | 封面、目录、扉页 |
| 拉丁字符 | Arial / Calibri | 仅技术字段（表名、接口数、版本号） |

内页 ≤2 套字体家族，美术层 ≤3 套。正文禁宋体大段，主标禁黑体，禁描边（封面字效除外）。

层级：封面主标 200px 交错 / 章节 PART 巨数 200px / 扉页中文标题 52px / 目录「目录」60px / B 区主标 34px / 卡片小标 26px / 正文 22–26px / 锚点数字 72–120px / 页码脚注 14px。

## 4. 英文使用

页面可见文字中文为主。仅结构性英文允许：`PART` / `CONTENTS` / `KPI` / `SSE` / `REST` / `MyBatis-Plus` / `Spring Boot` / `Vue3` / `H2` / `MySQL` / `JDK8` / `BCrypt`（后三者是技术专有名词，属技术字段）。
**禁**：A 区文字、SECTION 标识、kicker、THANK YOU、正文英文短语、图表轴英文、章节副标英译。

## 5. 信息密度

封面 4 字主标 + 副标 + 2 枚药丸 + ≥4 件装饰，整屏视觉 ≥85%。
目录 主标 + 6 编号载体 + 6 章节主题，≥80 字，装饰 ≥3 件。
扉页 PART 巨字 + 章节中文 + 中文副标 + 3 关键词点，≥30 字。
正文单主题：正文 + 主视觉，≥180 字，图占 C 区 ≥30%。
卡片组：每卡 ≥100 字，3 卡 ≥300 字。
数据页：主图 + 洞察 + 关键数字，≥80 字。

内页留白 ≤35%；卡片填充率 ≥75%；兄弟卡尾部 y 差 ≤16px；文字对比度 ≥4.5:1。
禁整屏暗蒙版；禁矩形色块压图。

## 6. 卡片规范（单页最多混用 2 种）

| 类型 | 规则 | 用途 |
|---|---|---|
| A 标准白卡 | 圆角 14px + 1px `#dfe4ea` 描边 + 白底无投影 | 通用首选 |
| B 警蓝头白卡 | 顶部警蓝卡头 50px + 白底正文区 | 多栏分组 / 强调 |
| C 藏蓝实心卡 | 藏蓝底白字，圆角 14px | 核心洞察；单页 ≤2 张 |

卡内 padding：上下 20 / 左右 24；卡间 gutter ≥24；卡内标题与正文间距 14。
所有卡片与可见元素严格 0°。推荐节奏：陈述型白卡为主、焦点型藏蓝卡少量，比例约 4:1。

## 7. 页面类型规范

**封面**：标题「案件指派系统」5 字横排（160/190/160/190/220 交错做不到时用 200 统一 + 「CaseFlow」金字副题）。金色叠加：文字投影 + 主标区域藏蓝光晕。副标用 0° 藏蓝飘带；汇报对象/日期用警蓝胶囊药丸。
禁单字背后填色矩形、倾斜飘带、整屏暗蒙版、英文副标翻译装饰。

**目录**：卡组列表型（6 章 → 3×2 警蓝头白卡），单一编号载体（阿拉伯数字 `01`–`06`），每卡含 章节名 + 讲什么 + 页码区间。

**章节扉页**：白底左右分屏 PART 现代版 —— 左 50%：PART + 巨数 01–06 + 警蓝短竖条 + 中文章节名 + 中文副标 + 3 关键词点；右 50%：主题图示出血铺满（禁暗蒙版）。底部保留 D 区三段装饰条。

**正文**：三栏/双栏并列卡每卡 ≥100 字；流程与架构用 SVG 图示（非等宽方框堆叠）；数据页主图 + 洞察框 + 锚点数字；决策清单用编号条目（编号徽标 + 决策 + 理由，≥3 条/组）。

**数据图表**：图例、坐标轴、单位中文；禁 3D、彩虹色、英文轴标签。

## 9. 最终硬闸门（交付前逐项过）

1. A 区出现任何文字/标识 → 返工
2. D 区缺三段装饰条或三段完全等宽 → 返工
3. B 区主标非中文、非宋体 Heavy、字号 <32px → 返工
4. 正文用衬线宋体，或主标用黑体 → 返工
5. 正文/图表/章节副标出现非结构性英文 → 返工
6. 色板越界（米白底、纯橙、红紫品红等禁色）→ 返工
7. 文字对比度 <4.5:1 或靠整屏暗蒙版保对比度 → 返工
8. 任意可见元素非 0° 旋转 → 返工
9. 出现印章语义元素、落款章 → 返工
10. L1 配图与页面主题不符，或通用大景在内容页凑数 → 返工
11. 卡片 padding/对齐/填充率/零旋转任一失守 → 返工
12. 占位文未清零 → 返工
